# TOMBO, as history

Before it became matrix, this repository was TOMBO, a single-file CSS design system, released
from `v0.1.0` to `v0.14.1`. This directory keeps what TOMBO wrote about itself: its reference
docs (foundations, layout, signatures, forms, charts, print, the topbar, `tombo.js`, the agent
guide, recipes and the upgrade guide), its specs and plans under `superpowers/`, and its
mockups and logo proposals under `reference/`. They describe TOMBO, not matrix, and their
links point at files that now live only on the frozen `tombo` branch and at TOMBO's tags,
which are the archive of the system as released.
