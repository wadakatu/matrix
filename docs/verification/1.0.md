# 1.0 — the verification matrix

The report task 6.2 (09) fills in. The rows are those of 05 ("Verification matrix for 1.0");
what each state means, and who can close a row, is in 05 ("The manual rows, and who can do
them"). **No manual row is done.** The automated rows below were run by the implementing agent
on the development machine, not yet by CI: the branch is not pushed.

- **passed**: done by a person, or by a test that is named. A manual row says who, on what
  device, system, browser or reader, at which versions, and when.
- **emulated**: a browser stood in for a device, or a script for a person. The entry says
  what was run. The row stays open.
- **open**: not done.

Release candidate: —. Commit: the tests were run on the tree of `3e512f0` (branch
`feat/matrix-phase-6`), 2026-11-24. Machine: Apple M3, macOS 27.2; Playwright 1.65.1 with its
Chromium 159.0.8154.6, Firefox 159.0 and WebKit 27.2 builds, headless. Address the pages were
reached at: the specimen build served from disk by the tests at `http://localhost:4173/specimens/`.
