# 1.0 — the verification matrix

**An outline. Nothing below has been run.** It is the shape of the report that task 6.2 (09)
fills in, written with the Phase 6 design so that an empty row cannot be mistaken for a
passed one. The rows are those of 05 ("Verification matrix for 1.0"); what each state means,
and who can close a row, is in 05 ("The manual rows, and who can do them").

- **passed**: done by a person, or by a test that is named. A manual row says who, on what
  device, system, browser or reader, at which versions, and when.
- **emulated**: a browser stood in for a device, or a script for a person. The entry says
  what was run. The row stays open.
- **open**: not done.
